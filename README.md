## 它是做什么的

小羊成卷不是一个普通文本编辑器，而是一个围绕“小说生产流程”设计的工作台。

它会引导你逐步完成：

- 项目设定：题材、核心卖点、读者预期、禁忌边界。
- 世界观搭建：世界规则、地理、势力、文化与基础设定。
- 人物设计：主角、配角、关系、动机、成长线。
- 故事大纲：卷纲、章节骨架、关键转折。
- 正文推进：围绕已有设定和上下文继续生成、修订和校对。
- 人工确认：每个关键产物都可以先看、再确认、再进入下一步。

更简单地说：它像一只安静但固执的牧羊犬，把散落的灵感、设定和章节一点点赶回队形里。

## 怎么使用

1. 下载并打开最新的 `.dmg` 安装包。
2. 将 `小羊成卷.app` 拖入 `Applications`。
3. 打开应用，先在设置里配置你的模型服务和 API Key。
4. 新建项目，按页面上的引导卡填写信息。
5. 每一步生成后先人工确认，满意再推进；不满意可以微调或废弃重来。

当前版本仍在早期迭代中，更适合愿意一起打磨流程的创作者使用。
